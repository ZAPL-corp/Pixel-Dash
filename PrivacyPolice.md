# 🔒 Политика конфиденциальности (Privacy Policy)
*8Мы уважаем вашу конфиденциальность. Данная Политика объясняет, какие данные Бот собирает и как они используются.**

## 1. Какие данные собирает Бот?
Для работы Бота используются только те данные, которые необходимы для его игрового функционала:

Ваш Discord ID и никнейм — для идентификации пользователя в Discord.

Игровой никнейм (ID аккаунта GDPS) — исключительно в случае, если вы используете команду верификации или привязки аккаунта.

Игровая статистика (звезды, демоны, монеты и т.д.) — Бот читает её из общедоступной базы данных нашего GDPS для вывода по командам вроде /profile.

## 2. Как используются данные?
Мы не собираем, не храним и не передаем третьим лицам ваши личные данные, пароли от аккаунтов или адреса электронной почты.

Все собираемые данные (Discord ID) используются исключительно внутри экосистемы Pixel Dash для корректной работы команд и выдачи ролей на сервере.

## 3. Хранение и безопасность данных
Все данные хранятся на защищенном сервере хостинга GDPSFH. Доступ к базе данных имеет только главный разработчик.

## 4. Удаление данных
Если вы хотите, чтобы Бот забыл ваш Discord ID или отвязал ваш аккаунт, обратитесь к создателю сервера через Discord. Ваша привязка будет удалена в течении определённого времени.
